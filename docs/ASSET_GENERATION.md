# Phase 1 generated visual assets

All assets below were created with the built-in `image_gen` mode, inspected, and copied into the Web application's public asset boundary. The repository does not depend on an external generation-time API key.

## `apps/web/public/images/nivalis-background.png`

```text
Use case: stylized-concept
Asset type: wide desktop website background for an About Me dashboard
Primary request: Create one original, polished anime-style background illustration of a luminous snow-blue city at dawn, designed to sit behind translucent glassmorphism dashboard cards.
Scene/backdrop: An airy winter cityscape with distant elegant towers, pale rooftops, a balcony railing, expansive glowing sky, drifting snow particles and a few tiny pink-lilac atmospheric accents. Keep the architecture dreamy and understated, with no recognizable real-world landmark.
Subject: One elegant, fully original blue-haired anime traveler standing on the balcony in the right third of the image, shown in a graceful three-quarter back view, wearing a refined winter coat with subtle blue and lilac details; calm contemplative pose, hair moving gently in the breeze. The character must not resemble any existing franchise character.
Style/medium: High-end original anime background art, luminous painterly cel-shaded illustration, soft atmospheric depth, delicate linework, sophisticated and serene rather than busy.
Composition/framing: 16:9 or wider landscape. Place the character entirely within the right third. Preserve generous clear, low-detail negative space across the left and center for large glass UI panels; keep important visual detail away from that overlay zone. Layered depth from soft foreground haze to distant city.
Lighting/mood: Radiant blue-white dawn, pearlescent haze, soft bloom, subtle sunlit snow, quiet hopeful mood.
Color palette: Predominantly snow white, icy cyan, powder blue and deep blue, with only tiny restrained pink-lilac accents.
Constraints: Background illustration only; no interface panels or cards; no text; no letters; no numbers; no logos; no watermark; no border; no signage; no duplicated people; no cropped character; avoid visual clutter in the left and center.
```

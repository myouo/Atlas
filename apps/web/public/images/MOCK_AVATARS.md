# Mock avatar provenance

The four `mock-avatar-*.webp` files are deterministic, non-AI placeholder avatars generated from fixed seeds with the DiceBear `lorelei-neutral` style.

- Generator: <https://www.dicebear.com/>
- Style creator: Lisa Wischofsky
- Style license: CC0 1.0
- Runtime behavior: files are committed static assets; Nivalis does not contact DiceBear in the browser or API.

These assets are development fixtures and do not represent real Provider identities.
